# Accessible Photo Gallery

An interactive photo gallery built with HTML and JavaScript.

## Files

- `index.html`: the page, with six images and their alt text
- `script.js`: shows captions on hover and focus, and adds tabindex to each figure on page load

## How to use

- **Mouse:** hover over a photo to show its caption.
- **Keyboard:** press Tab to move between photos. The caption appears on focus.

## Validation

- W3C Markup Validation Service: no errors
- WAVE: no errors
- aXe: no violations
